# zotero-obsidian-wiki-bridge
Dual-skill LLM Wiki for research: local-first paper processing and vault maintenance with Zotero + Obsidian, featuring schema-driven organization, incremental updates, and linting without external dependencies.

## Overview / 项目简介

**English** | **中文**

zotero-obsidian-wiki-bridge is a dual-skill LLM Wiki for academic research, built on Zotero + Obsidian. It takes a local-first approach to paper processing and knowledge base maintenance.

zotero-obsidian-wiki-bridge 是一个研究用的双技能 LLM Wiki 系统，基于 Zotero + Obsidian 构建，采用本地优先的论文处理与知识库维护方式。

## Key Features / 核心特性

| English | 中文 |
|---|---|
| **Schema-driven organization**: Automatically classify paper notes by predefined knowledge structures | **Schema 驱动组织**：按照预定义的知识结构自动归类论文笔记 |
| **Incremental updates**: Only process new or changed references, avoiding redundant work | **增量更新**：仅处理新增或变更的文献，避免重复工作 |
| **Linting**: Automatically check wiki consistency, backlinks, and frontmatter | **Linting**：自动检查 Wiki 一致性、反向链接和 frontmatter |
| **No external dependencies**: Runs fully locally without third-party services | **无外部依赖**：纯本地运行，不依赖第三方服务 |
